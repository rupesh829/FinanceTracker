
26. **Retirement data model is now flat (supersedes #25's expense/parent split).** Everything lives in `RetirementItems`: each row = one itemized cost with `name, tier, group, parentLine, unit, value` plus its own timeline (`isRecurring, anchor, startAge, endAge, startAtRet, endAtHorizon, every, active, infType`). Groups (`{tier,name}`) are stored in `RetirementConfig` row `groups`. The Tier Summary tab is read-only per group (collapsible tiers). Old `RetirementExpenses` rows are auto-migrated on load and the tab is cleared on next save. Amounts display as K / L / Cr via `fmtI`. Tax on withdrawals is an editable itemized line (Survival → Taxes), not a computed rate.
